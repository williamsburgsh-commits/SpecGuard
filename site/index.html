Architecture

How it works

Three layers: published limits, autonomous quoting, enforced shutdown.

01 · SPEC

Public spec is law

Max notional, inventory, drawdown, and leverage are pinned in JSON. Anyone can verify the hash onchain and on GitHub.

02 · QUOTE

Tiny quotes within limits

Post-only bid/ask on SOL-PERP subaccount 1. Pre-checks block orders that would breach before they hit the book.

03 · FLATTEN

Breach → cancel → close → RED

Armed automation cancels all orders, closes position, publishes attestation sigs. Status goes RED until manual reset.

Differentiator

Why SpecGuard

ClawPump ships risk-manager — advice only. SpecGuard inverts that.

risk-manager

Pre-trade sizing and drawdown recommendations. Last rule: never block a trade — only recommend.

specguard-enforcer

Blocks, then flattens. Skill law + armed automation. Judges verify shutdown on Solscan, not in a chat log.

STALE / copy-trade rules

Copy-trade is eligible only when operator status is GREEN and the heartbeat is fresh.

  • heartbeat_age = now - last_heartbeat_at
  • STALE if heartbeat age > TTL (300s)
  • Copy-trade eligible if GREEN and not STALE
